# Version 1 — archivée

La première version de la page, gardée en ligne telle qu'elle était :
https://ossamabenjemaa.github.io/athan/v1/

Elle contient ce que la refonte a mis de côté pour rester simple :

- le **mode veilleur** (l'athan joué par la page elle-même, écran allumé) ;
- les réglages fins : madhhab, règle des hautes latitudes, variante « par ville » ;
- le bloc **Valeurs à copier** détaillé et la recette complète de construction du raccourci,
  action par action ;
- le tuto de dépannage avec ses deux variantes (API AlAdhan et calendrier de mosquée).

Elle partage les fichiers de la racine (`../prayer-times.js`, `../calendriers/`, `../tuto/`,
`../raccourcis/`) : rien n'est dupliqué, et les calendriers restent à jour pour les deux
versions.
