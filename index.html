🕌 Athan

Les horaires de prière calculés sur ton téléphone, et l'appel qui sonne même en mode silencieux.

🧭 Lieu & méthode

Les horaires sont calculés hors ligne, sur l'appareil, et les réglages mémorisés dans le navigateur. Seule la recherche de ville interroge le réseau (géocodage AlAdhan) — une fois les coordonnées trouvées, tu peux couper les données.

    🔊 Mode veilleur page ouverte

    Faire sonner l'athan ici L'onglet reste ouvert et l'écran allumé ; le son passe le bouton silencieux.

    Aucun fichier : un simple carillon de secours est utilisé. Le fichier choisi est gardé sur l'appareil (rien n'est envoyé nulle part).

    🔕 Téléphone rangé recommandé

    Une page web ne peut sonner que si elle est ouverte. Pour un athan qui part tout seul, on s'appuie sur les réveils de l'app Horloge : ce sont les seuls sons qu'iOS laisse passer le bouton silencieux et les modes de concentration. Un raccourci les recrée chaque nuit avec les horaires du jour.

    1. Apporte l'athan en sonnerie : GarageBand → importe ton mp3 → coupe à 30 s → Partager → Sonnerie. (Ou une sonnerie achetée / déjà installée.)
    2. Crée une alarme dans Horloge, choisis cette sonnerie : les alarmes créées ensuite reprennent ce son par défaut.
    3. Raccourcis → Automatisation → Heure de la journée → 00:05, tous les jours, Exécuter immédiatement (sans confirmation).
    4. Une fois pour toutes : Réglages → Apps → Raccourcis → Avancé (ou Réglages → Raccourcis selon ta version d'iOS) → active Autoriser la suppression sans confirmation. Sans ça, iOS demande ton accord à chaque alarme supprimée, et l'automatisation reste plantée sur la question pendant la nuit.
    5. Première action : Rechercher des alarmes (Étiquette contient Athan), puis Supprimer les alarmes pour balayer celles de la veille.
    6. Ensuite seulement : Obtenir le contenu de l'URL avec l'adresse ci-dessous.
    7. Action Texte contenant Fajr,Dhuhr,Asr,Maghrib,Isha, puis Scinder le texte → séparateur Personnalisé → une virgule. Pas d'espace après les virgules : il resterait collé au nom et la clé serait fausse.
    8. Répéter avec chaque élément dans → vérifie que c'est bien Texte scindé (le résultat de Scinder) et non Contenu de l'URL : par défaut l'action reprend le résultat de celle qui la précède. Dedans, deux actions seulement : Obtenir la valeur du dictionnaire avec la clé data.timings. suivie de la variable Élément de répétition, dans Contenu de l'URL ; puis Ajouter une alarme à cette valeur, étiquette Athan + Élément de répétition.

    💡 La boucle évite de recopier cinq fois les deux mêmes actions — et donc cinq occasions de faire une faute de frappe. Attention à la clé : timings prend un s, et une clé erronée ne provoque pas d'erreur, elle rend juste une valeur vide et l'alarme n'est pas créée.

    ⚠️ L'ordre n'est pas décoratif : si Supprimer les alarmes se retrouve après les Ajouter une alarme, il efface les alarmes qui viennent d'être créées — on les voit apparaître puis disparaître. Vérifie aussi que l'entrée de l'action de suppression est bien le résultat de Rechercher des alarmes : sans entrée explicite, une action reprend le résultat de celle qui la précède.

    📋 Valeurs à copier touche = copié

    Tout ce qui se tape dans Raccourcis est là. Touche une ligne, puis colle dans le champ correspondant de l'action.

    ⚠️ Dans l'URL, remplace la date — par la variable Date actuelle au format perso dd-MM-yyyy — sinon toutes les nuits reprogrammeront les horaires d'aujourd'hui.

    Variante sans coordonnées (par ville)

    Plus facile à taper à la main sur le téléphone : AlAdhan accepte directement un nom de ville. Les horaires visent alors le centre de la ville — quelques secondes d'écart avec tes coordonnées exactes, sans conséquence.

    —
    Pourquoi pas une simple notification ?

    Les notifications (web ou app) sont muettes quand le bouton silencieux est mis : seules les alertes critiques passent, et elles demandent une autorisation spéciale d'Apple réservée aux apps natives. Les alarmes de l'app Horloge, elles, sonnent toujours — d'où le détour. À noter : leur volume suit le curseur Sonnerie et alertes, pas le volume multimédia.

    Calcul astronomique local (algorithme PrayTimes), aligné à ±1 min sur l'API AlAdhan.
