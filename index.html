    📲 Les alarmes sur votre iPhone

    —

    Construire le raccourci soi-même (dépannage)
    1. Première action : Rechercher des alarmes (Étiquette contient Athan), puis Supprimer les alarmes — avant les créations, sinon elles effacent ce qui vient d'être créé.
    2. Texte avec les paramètres, puis Définir la variable Paramètres.
    3. Obtenir le contenu de l'URL (voir la valeur ci-dessous).
    4. Texte Fajr,Dhuhr,Asr,Maghrib,Isha → Scinder le texte, séparateur Personnalisé, une virgule.
    5. Répéter avec chaque élément dans Texte scindé : dedans, Obtenir la valeur du dictionnaire puis Ajouter une alarme, étiquette Athan + Élément de répétition.

    📅 Source calendrier : l'URL pointe sur le fichier JSON de la mosquée, et une action de plus s'intercale — Obtenir la valeur du dictionnaire avec pour clé la Date actuelle au format dd-MM. Dans la boucle, la clé n'est plus que l'Élément de répétition.

    📋 Valeurs à copier touche = copié

    ⚠️ Dans l'URL AlAdhan, la date — doit être la variable Date actuelle au format dd-MM-yyyy.

    Pourquoi des alarmes plutôt qu'une notification ?

    Les notifications (web ou app) sont muettes quand le bouton silencieux est mis : seules les alertes critiques passent, réservées à des apps autorisées par Apple. Les alarmes de l'app Horloge, elles, sonnent toujours — d'où le détour. Leur volume suit le curseur Sonnerie et alertes, pas le volume multimédia.

    Horaires de mosquée recopiés tels quels ; sinon calcul astronomique local, aligné à ±1 min sur l'API AlAdhan.
    Vérifie toujours avec le calendrier de ta mosquée. 🤲
